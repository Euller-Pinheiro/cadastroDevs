# Formulário de cadastro

Formulário de cadastro com vários tipos de campo (texto, e-mail, seleção, opções) e validação nativa do HTML.

Projeto de estudo de 2023 (HTML e CSS), mantido aqui como registro da minha evolução.

## Como rodar

Abra o `formulario.html` no navegador.

## O que pratiquei

- Elementos e atributos de formulário
- Validação nativa do HTML5
- Estilização de formulários
